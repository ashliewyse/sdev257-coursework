# Module 01 - Hello World, Mobile

A React Native app for SDEV257 by Ashlie Wyse.

The app displays:
> Hi, my name is Ashlie Wyse, and I am a mobile developer

## Run in Expo Snack
1. Open https://snack.expo.dev.
2. Use Expo SDK 54.
3. Copy App.js into the Snack editor and use the dependency in package.json.
4. Select Web to preview in a browser.
5. To view on a physical phone, install Expo Go, select My Device, and scan the QR code.

Snack supplies the React, React Native, and Expo runtime. This package.json lists the additional dependency needed by this Snack project.

## How it works
- View provides the container.
- Text displays the personalized greeting.
- StyleSheet centers the content and makes the greeting bold.
- StatusBar chooses the appropriate status-bar style.

Adapted from the Chapter 16 starter example in React and React Native, Fourth Edition:
https://github.com/PacktPublishing/React-and-React-Native-4th-Edition/tree/main/Chapter16/my-project

The starter layout is preserved; the greeting is personalized as required.
